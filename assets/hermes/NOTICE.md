# Fotor for Hermes catalog artwork

These images are presentation assets for the Fotor plugin's Hermes catalog
listing. They are separate from the installed plugin and its existing Fotor logo.
The Muse composition combines preserved classical marble, a bronze scepter with
four V forms around an unlit star-shaped opening, and blue/gold pixel accents.

The selected AI-assisted artwork is retained as its original PNG bytes.
The cover uses the wording **FOTOR / FOR HERMES**. The square companion contains
no text. Neither image declares an Official or Verified catalog tier.

## Catalog use

Use the horizontal cover for the catalog entry's `image` field, with an HTTPS
raw GitHub URL pinned to the same public commit as the entry. The square is a
companion asset, not a native installer icon declaration or a product screenshot.
Publishing these files does not establish catalog admission or Desktop rendering.
